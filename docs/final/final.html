Part A · Stacks & Queues

Queue simulation (Hot Potato)

A queue where "passing the potato" means: take the person at the front and put them at the back.

Learn

Read this first. There are no questions in this zone.

Stack
LIFO
Last In, First Out. push and pop both use the top.
Queue
FIFO
First In, First Out. enqueue at the rear, dequeue from the front.
Hot Potato
1 pass = dequeue + enqueue
After k passes, the person now at the front is out.
Method
1
Write the queue front → rear on one line.
2
Move k people from the front to the rear.
3
The person now at the front is out.
4
Write the new line. Repeat until one is left.
Watch out. "Passed 3 times" means 3 people move to the rear. The 4th person (now at the front) is out, not the 3rd. When fewer people are left than passes, keep counting around the circle (2 people, 3 passes: X → Y → X).

Questions 1–4

Six students stand in a queue and play Hot Potato. In every round the potato is passed 3 times: each pass, the student at the front moves to the rear. After the 3 passes, the student now at the front is eliminated. The game goes on until only one student is left.

frontAnnBenCatDanEveFayrear

MCQ

Step through it
What to write on paper
Round 4: 3 people and 3 passes, so the queue comes back in the same order. That is correct, nothing is wrong.
3

Who is the winner?

MCQ
(3)EveThe only student never eliminated.
4

Yes or No: the queue does 20 dequeue operations in total.

Yes / No
(4)Yes, 20.Each round = 3 passes + 1 elimination = 4 dequeues. 5 rounds × 4 = 20.
Shortcut: dequeues = (n − 1) × (k + 1), with n players and k passes. (6 − 1) × (3 + 1) = 20.

Part B · Binary Search Tree

Insert, search, delete

Build the tree one key at a time. Then answer questions about the tree you drew.

Learn

Read this first. There are no questions in this zone.

Insert
Smaller ← · → Bigger
Start at the root every time. Go down until you find an empty spot.
Strings
Letter by letter
"Pim" < "Ploy": P = P, then i < l.
Duplicate
Ignored
Key already in the tree? Do not insert it (course rule, Guide #7).
Delete (2 children)
Min of the RIGHT subtree
Go right once, then left as far as possible. Leaf: just remove. 1 child: the child moves up.
Tree words you must know
WordMeaningWordMeaning
RootTop node, no parentSiblingsNodes with the same parent
Parent (internal)Has at least one childDepth of a nodeEdges from the root down to it
LeafHas no childrenHeight of the treeEdges on the longest root → leaf path
Common traps. Comparing only the first letter (Pim vs Ploy) · inserting a duplicate as an extra node · replacing a deleted node with the root of the right subtree instead of its minimum · forgetting that the final "found it" comparison counts.

Part C · Binary Tree Traversals

Pre-order, In-order, Post-order

Same tree, three orders. The only thing that changes is when you write the root.

Learn

Read this first. There are no questions in this zone.

Pre-order
Root → L → R
Write a node before its children. First box = root.
In-order
L → Root → R
Root sits in the middle. For a BST it comes out sorted.
Post-order
L → R → Root
Write a node after its children. Last box = root.
The flag trick
1
Draw one line around the tree, starting left of the root, hugging every node.
2
Pre: write a node when you pass its left side.
3
In: write it when you pass under it.
4
Post: write it when you pass its right side.
The exam hides the traversal in a story
If the question says…It means
"introduces each match the moment the show first reaches it"Pre-order
"the left side is listed before it, the right side after it"In-order
"a match can only be played after the matches that feed into it"Post-order
The trap: one-child nodes. Is the only child on the left or the right? It changes the in-order answer. Before you start, label every edge L or R. (The trees in the questions below already do this for you.)

Part D · Graphs

DFS, BFS, Dijkstra & the fastest route

The biggest part of the exam. Do Step 0 first, every time.

Learn

Read this first. There are no questions in this zone.

Step 0: write the adjacency list A → Z.
For every station, list its neighbours in alphabetical order. This one step prevents most DFS and BFS mistakes.
DFS · stack
Go deep, then backtrack
Take the first unvisited neighbour (A → Z). Dead end? Go back the way you came.
BFS · queue
Dequeue one, enqueue its new neighbours
Neighbours A → Z. Mark a station seen when it is enqueued, so it is never added twice.
Dijkstra
Smallest time first
Tie → alphabetical. Update only if strictly smaller (equal = keep the old one).
Route
Follow "Previous" backwards
Start at the target, follow Previous to the start, then reverse it.

Scenario: Weekend trip by train

Questions 1–5

You and your AIEE friends plan weekend trips around Bangkok by train. The map shows 7 real stations. Each line is a direct train link, and the number on it is the travel time in minutes (simplified, including walking between platforms). Every link works in both directions. Consider only BTS, MRT and Airport Rail Link trains. Each station has a two-letter code.

MO Mo ChitPH Phaya ThaiMA MakkasanLA Lat Krabang SI SiamAS AsokSA Sala Daeng
1

A travel vlogger films every station, starting at Siam (SI) and moving with Depth-First Search (DFS): keep travelling to a new station until there is none, then go back and try another link. In what order does she film the stations?

4 marks

Rule: From the current station, always travel to the unvisited neighbouring station that comes first alphabetically. If there is none, go back to the station you came from and continue from there.

After LA (a dead end), students jump to "the next station A → Z overall". Wrong: backtrack to MA and continue from there.

2

A metro app sends a crowd alert from Siam (SI) using Breadth-First Search (BFS): first to every station one link away, then to stations two links away, and so on. In what order do the stations receive the alert?

4 marks

Rule: When adding several neighbouring stations to the BFS queue, add them in alphabetical order.

Don't do BFS "level by level" in your head and sort each level A → Z. Use the queue: it gives the right order.
Step 0: adjacency list
Step through it
3

Use Dijkstra's Algorithm to find the fastest travel time from Lat Krabang using the rules below. The Lat Krabang row is already filled.

7 marks
  1. Next station: always finalise the unvisited station with the smallest time so far. If two or more stations tie, choose the one that comes first alphabetically.
  2. Updating: change a station's time and Previous only if the new time is strictly smaller. If the new time is equal, keep the old one.
  3. Order finalised: list the stations in the order they are finalised, starting with Lat Krabang.
The table is in alphabetical order, but "Order finalised" is the order you picked them. Don't mix them up.
3 moments that decide the marks
1
After MA: AS = 18 and PH = 18 tie → pick AS (alphabetical).
2
From PH: MO 30 → 28, SI 25 → 22. Previous becomes PH.
3
From SI: SA would be 22 + 3 = 25 = 25. Not strictly smaller → Previous stays AS.
Self-check: in "Order finalised" order, the times never go down: 0, 12, 18, 18, 22, 25, 28 ✔
Step through it
4

Use your table to write the fastest route from Lat Krabang (LA) to Mo Chit (MO), and its total travel time.

2 marks

Before the exam

Cheat sheet & self-check

Everything on one screen. Read it the night before and again just before you go in.

A Queue & Stack

  • Queue = FIFO. Write front → rear after every round.
  • Stack = LIFO. The top is the last one pushed.
  • Hot Potato: k passes, then the front is out.
  • Dequeues = (n − 1) × (k + 1).

B BST

  • Smaller ← · → bigger. Strings: letter by letter.
  • Duplicate = ignored.
  • Delete with 2 children = min of RIGHT subtree.
  • In-order of a BST = sorted. Use it to check.

C Traversals

  • Pre = Root L R (first box = root).
  • In = L Root R.
  • Post = L R Root (last box = root).
  • One-child node: left or right? Label edges first.

D Graphs

  • Write the adjacency list A → Z first.
  • DFS: go deep, backtrack the way you came.
  • BFS: queue, mark seen when enqueued.
  • Dijkstra: smallest; tie → A → Z; update only if strictly smaller.
  • Route: follow Previous backwards, then reverse.
Exam strategy
1
Show the working. Queue lines, the tree, the Dijkstra table. Working earns marks even if the final answer is wrong.
2
Underline the tie-break rules ("alphabetically", "strictly smaller"). The question is built around them.
3
Count the boxes. 9 boxes = 9 nodes. 7 boxes = 7 stations.
4
Unsure of a rule? Write your assumption next to the answer.
