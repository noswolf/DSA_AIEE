Module 0: Graph Theory Fundamentals

A Graph is a non-linear data structure modeling relationships. It consists of a set of vertices (nodes) and edges (connections). Graphs are used to build networks (social relationships, road maps, Internet routing) and map dependency relations (prerequisites, package compilers).

G = (V, E) Non-Linear Connections Reachability Traversal Order

Key Definitions

  • Vertex / Node: An individual data object or point in the graph (denoted as $v \in V$).
  • Edge / Arc: A link representing a relationship between two vertices (denoted as $e \in E$).
  • Adjacent: Vertices $u$ and $v$ are adjacent if there is an edge connecting them directly.
  • Path: A sequence of vertices such that consecutive vertices are connected by edges.
  • Cycle: A path that starts and ends at the exact same vertex.
  • Loop: An edge that connects a vertex to itself.

Graph Types & Edges

  • Undirected Graph: Edges have no direction. Edge $(u, v)$ means a mutual link. Degree of a node is the total number of incident edges.
  • Directed Graph: Edges have arrows. $(u, v)$ means you can only go from $u$ to $v$.
  • In-Degree: Number of incoming edges pointing directly to the node.
  • Out-Degree: Number of outgoing edges pointing away from the node.

Module 1: Graph Representation

To implement graph algorithms in computer programs, we need structures that record nodes and their connections. The two primary mathematical representations are Adjacency Matrix and Adjacency List.

Adjacency Matrix

A 2D array of size V x V where element matrix[i][j] is 1 (or weight) if an edge exists from node i to node j, and 0 otherwise.

# Adjacency Matrix representing 3 nodes A, B, C
# Link: A → B (weight 2), B → C (weight 5)
matrix = [
    [0, 2, 0], # A's outgoing to [A, B, C]
    [0, 0, 5], # B's outgoing to [A, B, C]
    [0, 0, 0]  # C's outgoing to [A, B, C]
]

Good for dense graphs, but wastes memory O(V^2) for sparse graphs.

Adjacency List

An array or dictionary where each vertex maps to a list/dictionary of its immediate neighbors and edge costs.

# Adjacency List using Python dict
# Node maps to a dict of neighbor: weight
graph = {
    'A': {'B': 2},
    'B': {'C': 5},
    'C': {}
}

Standard representation for algorithms. Memory efficient O(V + E).
